# Life Events

Code: `packages/core/src/planning.ts`; UI `/app/events`.

Templates: travel (before-you-go, documents, packing), moving home, starting school, starting university, event planning, celebration, big purchase & delivery, personal admin project. Each event has dates, location, notes, status (planning, in progress, done, cancelled), a grouped checklist, participants with responsibilities, and linked documents/bookings (from the Vault). A reminder fires 7 days before the start; it stops when the event is done or cancelled. Life events appear on the calendar overlay.
